# mtfind

Многопоточный поиск подстроки по маске в текстовом файле. C++20.

Маска — строка, где `?` обозначает любой символ (кроме перевода строки).
Файл — 7-bit ASCII, до 1 ТБ. Поиск регистрозависимый, вхождения
непересекающиеся и находятся в пределах одной строки.

## Сборка и запуск

Рекомендуемый компилятор — **GCC (g++) 12 или новее** (полная и стабильная
поддержка C++20, включая ranges/views). Другой
компилятор можно указать через `-DCMAKE_CXX_COMPILER=<путь>`.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j && ./build/mtfind <file> <mask>
```

- `<file>` — путь к текстовому файлу (7-bit ASCII, до 1 ТБ);
- `<mask>` — маска поиска до 100000 символов, `?` — любой символ (кроме перевода строки).

Вывод: первая строка — количество вхождений, далее для каждого
`номер_строки позиция_в_строке найденный_текст`; нумерация с 1, текст —
фактический фрагмент файла. Порядок вывода совпадает с порядком в файле.
